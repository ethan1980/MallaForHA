# Malla for Home Assistant

Malla is a native Home Assistant integration for MeshView.

Unlike a simple REST sensor, Malla provides:

- Native MeshView API client
- Packet parsing
- Sent packets
- Reported packets
- Circuit Breaker protection
- Local cache
- Future native chat support
- Future statistics and diagnostics

## Features

- ✅ Sent packets
- ✅ Reported packets
- ✅ Automatic cache
- ✅ Circuit Breaker
- 🚧 Native chat
- 🚧 Statistics
- 🚧 Health monitoring

## Installation

### Manual

Copy:

custom_components/malla

into:

config/custom_components/

Restart Home Assistant.
